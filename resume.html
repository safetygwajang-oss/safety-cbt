1. 자기소개서는 무엇을 보는 글인가

평가자는 지원자의 인생을 궁금해하지 않습니다. “이 사람을 뽑으면 우리 일이 되는가” 하나만 봅니다. 자기소개서는 자기 고백문이 아니라 증거 제출 문서입니다.

평가 항목평가자가 확인하는 것합격 글의 특징
직무 적합성공고 요건과 경험이 겹치는가공고 단어를 그대로 쓴다
성과 재현성회사에서도 같은 성과가 날까과정·판단 근거가 있다
조직 적합성같이 일할 만한가갈등 상황의 대응이 구체적
지원 진정성아무 데나 넣은 건 아닌가회사 사업·이슈를 안다
문서 역량보고서를 맡길 수 있나두괄식·짧은 문장
모든 문장은 “그래서 뭘 할 수 있는데?”에 답해야 합니다. 답이 안 되는 문장은 지우세요.

2. 채용공고 해독법 — 키워드 추출

자기소개서의 정답은 공고 안에 있습니다. 공고를 3덩어리로 자르는 것부터 시작합니다.

  • 담당업무 → 입사 후 실제로 할 일. 입사 후 포부의 재료가 됩니다.
  • 필수요건 → 없으면 탈락. 직무역량 항목에서 반드시 증명합니다.
  • 우대사항 → 경쟁자와 벌어지는 지점. 하나라도 해당되면 앞쪽에 배치합니다.
  • 인재상·핵심가치 → 회사 홈페이지에서 확인. 성격/가치관 항목의 기준입니다.
공고 표현실제 요구 역량준비할 경험
유관부서 협업이해관계 조율·설득부서 간 의견 충돌 해결 사례
데이터 기반 개선수치 해석·개선 실행지표 개선 전/후 수치
다수 프로젝트 동시 수행우선순위 관리일정 압박 상황 처리 방식
대외 기관 대응법규 이해·문서 대응감사·심사·점검 대응 경험
공고에 없는 역량을 자랑하는 건 감점입니다. “좋은 경험”보다 “요구된 경험”이 먼저입니다.

3. STAR 기법 — 경험을 근거로 바꾸는 틀

단계쓸 내용분량흔한 실수
S 상황언제·어디서·어떤 조건15%배경 설명이 절반을 차지
T 과제내가 맡은 문제와 목표15%“팀이”만 있고 “내가”가 없음
A 행동내가 한 판단과 실행50%노력했다·최선을 다했다
R 결과수치 변화 + 배운 점20%결과 없음, 소감만
❌ 팀원들과 소통하며 열정적으로 프로젝트를 완수했습니다.
검증 불가능한 자기평가 → 평가자는 아무 정보도 얻지 못합니다.
✅ 설비 정지 원인을 3개로 좁힌 뒤 점검 주기를 주 1회로 바꿔, 6개월간 비가동 시간을 32시간에서 9시간으로 줄였습니다.
판단 → 실행 → 수치. 같은 성과를 낼 사람으로 보입니다.
수치가 없으면 비율·횟수·기간·인원으로 바꿔보세요.

4. 항목별 작성 공식

항목구성 공식핵심
지원동기회사 사업/이슈 → 내 경험 접점 → 기여 지점“존경합니다” ❌ / “이 사업에 이 경험이 쓰입니다” ✅
입사 후 포부1년(적응·습득) → 3년(주도) → 5년 이상(전문성)담당업무 문장을 그대로 인용
직무역량필수요건 1개 = 사례 1개 (STAR)가장 강한 근거를 첫 줄에
성장과정가치관 형성 사건 → 현재 일하는 방식가족 소개가 아니라 직무 연결
성격 장단점장점=직무 강점 / 단점=개선 행동 진행형“꼼꼼해서 느립니다” 식 위장 금지
협업·갈등갈등 원인 분석 → 내 조정 행동 → 관계 유지상대를 이긴 이야기 ❌
실패 경험실패 인정 → 원인 규명 → 재발 방지 적용실패가 아닌 성공담으로 바꾸지 말 것

5. 소제목·첫 문장 만들기

  • 소제목은 15자 이내, 결과나 방법이 드러나야 합니다. (예: “비가동 32시간을 9시간으로”)
  • 첫 문장은 두괄식. 결론·수치·문제 정의 중 하나로 시작합니다.
  • “저는 ~한 사람입니다”로 시작하지 마세요. 평가자가 가장 많이 읽고 가장 안 믿는 문장입니다.
  • 문장은 60자 이내, 한 문장에 메시지 하나.
첫 3줄에서 승부가 납니다. 서류 1건에 주어지는 시간은 평균 1~2분입니다.

6. 제출 전 체크리스트 & 감점 표현

  • ☐ 회사명·직무명 오기 없는가 (다른 회사명 남으면 즉시 탈락)
  • ☐ 공고 키워드가 각 항목에 최소 1회씩 들어갔는가
  • ☐ 모든 사례에 수치가 있는가
  • ☐ 60자 넘는 문장을 잘랐는가
  • ☐ 글자수 기준의 90~100%를 채웠는가
  • ☐ 소리 내어 읽었을 때 걸리는 문장이 없는가
감점 표현 — 열정을 갖고 / 최선을 다해 / 남들보다 뛰어난 / 소통의 달인 / 뼈를 묻겠습니다 / 시켜만 주신다면 / 귀사 (→ 회사명 직접 표기)
